● 60~90: 매우 치열. 기존 상위 블로그가 강력함
● 90+: 극심한 경쟁. 다른 키워드를 찾는 것이 효율적

🤖 블로그 프롬프트 메이커

비워두면 AI가 먼저 5~8개 제목을 추천하고, 사용자가 번호 선택 후 작성합니다.

👥 블로그 분석

블로그 ID를 줄 단위로 입력하세요 (최대 20개). 각 블로그의 최근 10개 글 노출 여부와 인플루언서 여부를 분석합니다.

📖 사용 가이드

🔍 키워드 경쟁도 분석

분석할 키워드를 최대 10개까지 입력 → 경쟁도 분석 클릭. 등급(S~F), 누적 문서수, 월 발행수, 트렌드 차트, 추천 키워드, 연관 50개를 한 번에 확인합니다.

📝 포스팅 분석

블로그 글 URL 입력 시 노출 여부, 본문 글자수/이미지/링크 등 글 자체의 품질을 분석합니다. (개발 중)

🥇 키워드 순위 확인

블로그 ID + 키워드 1~10개 입력 → 각 키워드 검색 시 본인 블로그가 몇 위에 노출되는지 확인합니다.

🩺 글 누락 진단

블로그 ID 입력 시 RSS에서 최근 10개 글을 가져와 정확 구문 검색으로 인덱스 누락 여부를 진단합니다.

👥 블로그 분석

블로그 ID 최대 20개를 한 번에 분석. 인플루언서 여부, 최근 30일 글수, 최근 포스팅일, 최근 10개 글 노출 진단을 표시합니다.

⚙️ 등급 의미

  • S 황금키워드 — 검색량 대비 경쟁이 매우 낮음
  • A 매우 좋음 — 공략 시 상위노출 유리
  • B 공략 추천 — 양호한 균형
  • C 보통 — 보편적 키워드
  • D 경쟁 치열 — 노력 필요
  • E 상위노출 어려움 — 강한 경쟁
  • F 진입 비추천 — 매우 어려움
