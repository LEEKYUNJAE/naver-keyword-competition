경쟁도 수치 해석 (누적문서 ÷ 유효검색 기준)
● ~5: 검색은 있지만 글이 적음. 빠르게 선점 가능
● 5~22: 적당한 경쟁. 좋은 글이면 상위노출 가능
● 22~38: 보통 경쟁. SEO 최적화 + 콘텐츠 전략 필요
● 38~60: 치열한 경쟁. 롱테일/차별화 필수
● 60~90: 매우 치열. 기존 상위 블로그가 강력함
● 90+: 극심한 경쟁. 다른 키워드를 찾는 것이 효율적

📝 포스팅 분석
💎 블로그 아이디 또는 블로그 주소를 입력하면 → 최근 10개 글이 자동으로 나옵니다. 각 글을 개별 분석할 수 있어요.
📄 글 주소를 입력하면 → 해당 글을 단독으로 깊이 분석합니다.
🥇 키워드 순위 확인

블로그 ID와 키워드를 입력하면, 각 키워드 검색 시 본인 블로그가 몇 위에 노출되는지 확인합니다.

🩺 글 누락 진단

블로그 ID 입력 시 RSS에서 최근 10개 글을 가져와 정확 구문 검색으로 인덱스 누락 여부를 진단합니다.

🤖 블로그 글쓰기 프롬프트

다퍼남 v2.1 지침 기반으로 입력만 하면 ChatGPT·Claude·Gemini용 통합 프롬프트가 자동 생성됩니다. 생성된 프롬프트를 복사해서 AI에 붙여넣으면 즉시 블로그 글이 작성됩니다 (API 비용 0원).

📋 생성된 프롬프트
📌 사용 안내:
• ChatGPT: 새 창에서 입력칸에 자동 입력됨 → Enter만 누르면 됨
• Claude / Gemini: URL 자동입력 미지원 (브라우저 보안). 클립보드에는 자동 복사되니 새 창에서 Ctrl+V → Enter
🖼️ 이미지 자동 생성기

완성된 블로그 글을 붙여넣으면 소제목별로 이미지 생성 프롬프트가 자동으로 만들어집니다. 각 프롬프트마다 ChatGPT/Gemini 새 창 자동 입력 버튼이 제공됩니다.

📖 사용 가이드

🔍 키워드 경쟁도 분석

분석할 키워드를 최대 10개까지 입력 → 경쟁도 분석 클릭. 등급(S~F), 누적 문서수, 월 발행수, 트렌드 차트, 추천 키워드, 연관 50개를 한 번에 확인합니다.

📝 포스팅 분석

블로그 글 URL 입력 시 노출 여부, 본문 글자수/이미지/링크 등 글 자체의 품질을 분석합니다. (개발 중)

🥇 키워드 순위 확인

블로그 ID + 키워드 1~10개 입력 → 각 키워드 검색 시 본인 블로그가 몇 위에 노출되는지 확인합니다.

🩺 글 누락 진단

블로그 ID 입력 시 RSS에서 최근 10개 글을 가져와 정확 구문 검색으로 인덱스 누락 여부를 진단합니다.

👥 블로그 분석

블로그 ID 최대 20개를 한 번에 분석. 인플루언서 여부, 최근 30일 글수, 최근 포스팅일, 최근 10개 글 노출 진단을 표시합니다.

⚙️ 등급 의미

  • S 황금키워드 — 검색량 대비 경쟁이 매우 낮음
  • A 매우 좋음 — 공략 시 상위노출 유리
  • B 공략 추천 — 양호한 균형
  • C 보통 — 보편적 키워드
  • D 경쟁 치열 — 노력 필요
  • E 상위노출 어려움 — 강한 경쟁
  • F 진입 비추천 — 매우 어려움
